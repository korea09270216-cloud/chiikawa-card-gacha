# CHIIKAWA — SECRET PACK

검은 우주에서 카드 꾸러미를 고르고, 밀봉된 팩을 뜯어 카드 한 장을 만납니다.

1. 처음 선택: **꾸러미 → 밀봉 카드팩 → 개봉 → 카드**.
2. 같은 팩에서 재뽑기: **새 카드팩 → 개봉 → 카드**. 꾸러미 선택 모션을 반복하지 않습니다.
3. 다른 꾸러미로 바꾸려면 왼쪽 위 ‘꾸러미 선택’을 사용합니다.

## 카드 목록

- 개봉 후 `카드 목록 · 카드뽑기 · 카드 저장`을 제공합니다.
- 목록은 카드팩별 탭으로 분리되며, 팩마다 뽑기 후보와 수집 기록이 독립적입니다.
- 뽑은 카드만 그림·이름·보유 수량을 표시하고, 누르면 확대해서 원본을 저장할 수 있습니다.
- 미획득 카드는 검은색 카드와 `?`로 표시합니다. 이름, 그림, 미획득 이미지 요청 및 다운로드 링크를 생성하지 않습니다.
- 기존 `chiikawa-awakening-v1` 기록을 그대로 사용합니다. 기록이 있는 재방문자는 첫 화면에서 목록을 열 수 있습니다.
- 각 카드 확률은 해당 팩 안에서 동일하며, 중복이 나올 수 있습니다. 현재 시크릿 팩은 6종입니다.

## 연출

- 일반 개봉은 이미지 로딩 후 약 7.45초: 에너지 모으기 → 포일 윗부분 찢기 → 빛 분출 → 카드 뒷면 등장 → 여운 → 뒤집기 및 반짝임.
- 효과음: 저음 상승, 길게 찢기는 포일, 충격·바람, 긴 금속음, 순차적인 반짝임.
- 자기장 인터랙션은 커서와 요소 사이의 거리 감쇠와 방향 단위벡터를 사용합니다.
- 조명 위치는 고정됩니다. 직선 반사선의 위치는 카드의 실제 회전각에만 연동되며, 포인터 좌표를 광원 위치로 쓰지 않습니다. 유휴 상태의 작은 회전으로 터치 환경에서도 반사선이 지나갑니다.
- 반사광·홀로그램·등장 스윕은 하나의 `.card-surface` 내부에 있으며, 공통 `clip-path`, 둥근 모서리, `overflow:hidden`, `contain:paint`, `isolation:isolate`로 잘립니다.
- 원본 756 × 1056 카드의 모서리를 분석해 바깥 여백을 제외하는 마스크를 사용합니다. 원본 PNG는 변경하지 않았습니다.
- 배경 광선은 WebGL 볼류메트릭 ray marching과 CSS 근사입니다. 하드웨어 RTX 경로 추적이 아닙니다.
- 모션 감소 설정, 터치 입력, 키보드 조작, 이미지 실패 시 재시도, 백그라운드 애니메이션 중단을 지원합니다.

## 카드팩 추가

`packs.js`의 `PACK_SETS` 배열에 항목을 추가하면 꾸러미 선택과 카드 목록 탭이 자동으로 생성됩니다.

- `id`, `storageKey`: 다른 팩과 겹치지 않는 안정적인 값.
- `label`, `brand`, `edition`: 목록과 카드 뒷면의 표시 이름.
- `boxImage`, `wrapperImage`: 꾸러미와 개별 포장 이미지 경로.
- `cards`: 각 카드의 고유 `id`, `name`, `image`.

기존 수집 기록을 보존하려면 출시한 팩의 카드 배열 순서를 유지하고 새 카드는 뒤에 추가하세요. 기본 카드 비율은 756:1056입니다.

## 실행

```sh
npm start
npm run check
```

Python 3과 Node.js를 사용하며, 별도 빌드나 런타임 패키지 설치는 필요하지 않습니다. GitHub Pages는 `main` 브랜치의 `/`를 제공합니다.

원본 카드 6장: `assets/cards/`. 내장 이미지 생성으로 만든 꾸러미와 포장지: `assets/secret-box.png`, `assets/secret-pack.png`. [생성 프롬프트](assets/pack-art.md).

비공식 팬 프로젝트입니다. 캐릭터 권리는 원권리자에게 있습니다. 결제나 현금성 보상은 없습니다.
