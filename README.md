# 치이카와 · 마수각성 컬렉션

6종 SSS 카드를 무료로 뽑고 수집하는 정적 웹사이트입니다. 원본 PNG(756 × 1056)를 그대로 사용합니다.

- 1장 / 6장 뽑기, 각 카드 확률 1/6, 중복 허용
- 브라우저 로컬 저장, 수집률, 보유 수량, 보유 카드 필터
- 카드 확대, 원본 PNG 다운로드, 선택적 효과음
- 근접 자기장: 거리 감쇠 × 방향 단위벡터 기반 3D 기울기와 리프트, idle 부유, 스크롤/이탈 복귀
- WebGL 볼류메트릭 광선: 24단계 ray marching, 바닥 ray/plane 교차, CSS 홀로그램·반사광
- 광선 효과는 하드웨어 RTX 경로 추적이 아닌 웹용 실시간 근사입니다. WebGL 불가 환경에서는 CSS 빛줄기로 대체합니다.
- 모션 감소 설정, 터치기기, 백그라운드 탭, 화면 밖 렌더링 중단 지원

## 실행

```sh
npm start
```

http://127.0.0.1:4173/ 에서 확인할 수 있습니다. Node 패키지 설치나 빌드 없이 GitHub Pages에서 바로 제공됩니다. 실행 스크립트는 Python 3을 사용합니다.

```sh
npm run check
```

GitHub Pages: `main` 브랜치의 `/` 경로를 배포합니다.

수집 기록은 기기·브라우저별 localStorage에 저장됩니다. 브라우저 데이터 삭제 시 사라집니다. 서버 계정 동기화, 결제, 현금성 보상은 없습니다.

이 프로젝트는 사용자가 제공한 이미지로 제작한 비공식 팬 컬렉션입니다. 캐릭터 권리는 원권리자에게 있습니다.
