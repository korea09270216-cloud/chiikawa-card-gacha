# CHIIKAWA — SECRET PACK

검은 우주에 미개봉 카드팩 하나만 떠 있습니다. 팩을 클릭하면 포일 윗부분이 뜯어지고, 틈에서 빛이 새어 나오며, 무작위 카드 한 장이 등장합니다.

- 첫 화면: 검은 공간, 작은 별, 밀봉 팩 하나. 제목·메뉴·카드 목록·도감 없음.
- 개봉 전에는 카드 이미지·이름·종류를 UI에 노출하지 않으며, 카드 이미지 요청도 하지 않음.
- `sealed → loading → tearing → opening → revealing → revealed` 순서. 연속 클릭으로 중복 개봉하지 않음.
- 한 팩에 카드 한 장. 6종 동일 확률, 중복 가능. 기존 localStorage 수집 기록 보존.
- 개봉 후 ‘한 팩 더’와 원본 PNG 저장. 다음 팩으로 돌아가면 이전 결과 DOM도 제거.
- 포일 찢김, 지익 효과음, 광선·입자·충격파, 3D 등장, 홀로그램 반사광.
- 사용자 제공 자기장 문서의 방향 단위벡터 × 거리 감쇠를 적용. 터치·모션 감소 설정 존중.
- WebGL 20단계 볼류메트릭 ray marching. 하드웨어 RTX 경로 추적이 아닌 웹용 광선 근사이며, 미지원 시 CSS 광선으로 동작.
- 백그라운드 애니메이션 정지, 이미지 오류 시 재시도, 키보드 개봉 지원.

## 로컬 실행

```sh
npm start
npm run check
```

Python 3과 Node.js를 사용합니다. 빌드나 런타임 패키지 설치가 필요 없는 정적 사이트입니다. GitHub Pages는 `main` 브랜치의 `/`를 제공합니다.
